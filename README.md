# Blending 2.0

Este repositorio contiene **Azure Functions** desarrolladas en **C#** como parte del proyecto **Blending 2.0**.  
El código está organizado en múltiples proyectos de Functions que exponen operaciones relacionadas con el sistema de homogenización y blending.

## Estructura del repositorio
- `src/` → Código fuente de las Azure Functions.
- `tests/` → Pruebas unitarias y de integración.
- `docs/` → Documentación complementaria del proyecto.

## Requisitos previos
- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [Azure Functions Core Tools](https://learn.microsoft.com/azure/azure-functions/functions-run-local)
- Una cuenta de Azure y permisos para desplegar recursos.
